# Genomic Ancestry Analysis

This repository contains a computational project for analyzing genomic ancestry and population affinity using Illumina microarray data and the 26 populations from the 1000 Genomes Project.

## Files

* **`guia_ancestralidade_genomica_colab.ipynb`** — Executable Google Colab notebook containing the complete analysis pipeline, including genotype harmonization, quality control, allele-frequency analysis, LD pruning, PCA, k-NN classification, population-distance analysis, mixture modeling, and validation.

* **`ENUNCIADOtrabalho 1 ancestralidade genomica.pdf`** — Project assignment and guidelines, describing the objectives, required analyses, reference populations, visualizations, validation procedures, and methodological requirements.

* **`RELATÓRIOAnálise_de_Ancestralidade_Genômica.pdf`** — Final report presenting the methodology, results, discussion, validation, comparison of methods, and limitations of the genomic ancestry analysis.

## Main Technologies

Python · Google Colab · PLINK 2 · NumPy · Pandas · Scikit-learn · SciPy · PCA · k-NN

## Reference

The analysis uses the 1000 Genomes Project as the population reference panel.
